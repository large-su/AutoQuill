# 归档探针与调试脚本

| 项目 | 内容 |
|---|---|
| **适用版本** | 历史记录（v4.x 全期） |
| **最后更新** | 2026-10-01 |
| **状态** | 已归档 |
| **说明** | 开发过程中用于真机取证的一次性探针与调试脚本，问题定位完成后归档 |

## 目录结构

| 目录 | 内容 |
|---|---|
| `probes/` | 针对具体线上问题编写的只读探针与验证脚本 |

## 这些脚本的价值

它们记录了**真机 DOM 结构、接口响应、界面行为**的取证方式，是排查同类问题时的
第一手参考。例如：

- `diagnose_publish_*.py` —— 草稿发布卡住 / 点不动 / 找不到按钮的取证
- `probe_progress_*.py` —— 打卡进度数据来源的探查
- `verify_publish_*.py` —— 发布链路修复后的验证
- `verify_update_flow.py` / `verify_comment_fallback.py` —— 更新与评论兜底的演练验证

## 约定

- **只读**：不再修改。需要新的探针时在 `tools/archive/probes/` **之外**新建，
  避免与历史脚本混在一起；
- 这些脚本依赖当时的页面结构与数据目录，**随时可能失效**；
- 多数脚本需要登录态与真实数据目录，运行前请确认参数，不要直接用默认值跑。

## 已知运行注意

- 部分脚本默认读取 `%APPDATA%\AutoQuill`，若数据目录不同请显式传 `--data-dir`；
- 涉及"点击发布 / 发送"的脚本一律提供 `--dry-run` 或默认不发送，运行前确认。
