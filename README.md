## 功能

运行在本机的自动化写作工具，像人一样操作浏览器完成整个流程：

1. **选题** —— 从知乎创作中心的推荐问题中筛选故事类话题
2. **提取** —— 打开问题页，提取高赞回答全文与互动数据
3. **生成** —— 交给大模型，按指定作者的文风创作新故事
4. **发布** —— 写入知乎草稿，确认后手动发布

| 功能 | 说明 |
|---|---|
| 一键安装 | 安装包安装即用，不需要 Python / 命令行 |
| 独立窗口 | 自带应用窗口（WebView2 内核），不占用浏览器标签页 |
| 首启引导 | 首次打开弹出设置向导（Edge → API Key → 知乎登录） |
| 应用内更新 | 内置「检查更新」，一键完成下载、校验、安装与重启 |
| 批量生成 | 一次运行多轮，自动选题 → 生成 → 写入草稿 |
| 文风模仿 | 采集指定作者的故事，提炼写作风格并在生成时注入 |
| 叙事兑现自检 | 同一次生成中检查开篇、人物行动依据与完整结尾，保留不同题材和文风 |
| 质量筛选 | 评分同时采样开头、中段与结尾，结合读者视角筛选批量稿件 |
| 故事采集 | 自动浏览作者主页，滚动加载并采集全部故事（支持断点续采） |
| 自动化调度 | 按计划自动撰写、发布草稿、回复评论、完成每日打卡 |
| Web 控制台 | 独立窗口内操作（`http://127.0.0.1:8787`），实时日志与历史故事 |
| 双生成通道 | API 直调（快速稳定）或免费网页版（浏览器操作） |
| 数据本地化 | 配置、登录态、采集库、成品全部保存在本机 |

## 系统要求

- **Windows 10 / 11**（64 位）
- **Microsoft Edge**（系统自带，或从 [microsoft.com/edge](https://www.microsoft.com/edge) 安装）
- 一个大模型 API Key（如 DeepSeek）。**可选** —— 也可以完全使用免费的网页版通道

> 不需要安装 Python，不需要命令行操作。

## 安装

1. 打开 [Releases](https://github.com/large-su/AutoQuill/releases)，下载最新版
   `AutoQuill-Setup-<版本>.exe`；
2. 双击运行，按提示完成安装；
3. 首次启动会打开设置向导，按三步完成配置。

> **关于 SmartScreen 提示**：安装包未做商业代码签名，Windows 会提示「未知发布者」。
> 点「更多信息」→「仍要运行」即可。安装后使用不受影响。

启动后会静默检查一次更新，有新版时顶部按钮会提醒。
手动点击更新并确认后，自动完成下载、校验、安装与重启，中途无需再次确认。
发布页提供 EXE 安装包与 SHA256 校验文件。

**校验安装包**（可选）：同目录的 `.sha256` 文件为安装包的 SHA256 值。

```powershell
certutil -hashfile AutoQuill-Setup-5.3.1.exe SHA256
```

## 首次使用

首次启动弹出向导，共三步：

| 步骤 | 内容 |
|---|---|
| ① 浏览器 | 检测 Microsoft Edge（系统自带，通常无需操作） |
| ② 生成通道 | 选择 API（填写 Key）或 Web 网页版（免费，需登录对应网站） |
| ③ 知乎登录 | 在弹出的 Edge 窗口中登录知乎，检测到登录后自动保存 |

三步完成后即可在主界面开始工作。

## 使用指南

### 主界面

左列下拉切换页面：

| 页面 | 用途 |
|---|---|
| 工作台 | 选题、生成、发布的主流程与运行日志 |
| 作者蒸馏 | 采集作者故事并提炼文风 |
| 草稿箱素材 | 预览、筛选、批量删除知乎草稿 |
| 数据看板 | 发布量、阅读、赞同等效果统计 |
| 自动化 | 任务计划、配额、时间轴与打卡状态 |
| 设置 | 生成通道、模型、参数与登录状态 |

### 运行模式

| 模式 | 行为 |
|---|---|
| 经典模式 · 完整链路 | 选题 → 提取 → 生成 → 写入草稿（带格式守则） |
| 纯净模式 · 完整链路 | 流量选题 → 提取 → 极简生成 → 审核 → 写入草稿 |
| 批量运行 | 一次运行多轮完整链路 |
| 环节测试 | 只跑单个环节（如仅生成，不发布） |

### 自动化

「自动化」页可配置按计划自动执行的任务：

| 任务 | 说明 |
|---|---|
| 全链路撰写 | 自动完成选题到写入草稿的全过程 |
| 发布草稿 | 按「从旧到新」逐篇发布草稿（公开可见，不可逆） |
| 回复评论 | 挑选最友善的读者评论回复（可先以演练模式运行） |
| 打卡互动 | 读取创作打卡页，补做未完成的关注 / 赞同 / 评论 |

配置项包括运行时段、每日数量上限、同类最小间隔。打卡与回复评论为一天一班，
不设间隔。时间轴会显示每班计划的时刻与执行结果。

## 数据与隐私

所有数据保存在本机，不上传到任何第三方服务（调用大模型 API 除外）。

| 路径 | 内容 |
|---|---|
| `%APPDATA%\AutoQuill\config\` | 配置、登录态快照 |
| `%APPDATA%\AutoQuill\data\` | 采集库、生成稿、发布台账、自动化状态 |
| `%APPDATA%\AutoQuill\logs\` | 运行日志（按日期命名） |
| `%APPDATA%\AutoQuill\data\browser_profile\` | 浏览器配置（含登录态，请勿分享） |

数据目录与程序目录分离：卸载或升级不会删除数据。
高级用法：环境变量 `AQ_DATA_DIR` 可指定自定义数据目录。

## 常见问题

**安装时 Windows 提示「未知发布者」/ SmartScreen 拦截？**
软件未做商业代码签名，属正常提示。点「更多信息」→「仍要运行」。安装后使用不受影响。

**必须配置 API Key 吗？**
不是。可以跳过第 2 步，在控制台把生成通道切到 Web 网页版（免费）。推荐配置 Key，速度更快更稳定。

**知乎登录一直失败 / 提示登录失效？**
点右上角「设置」重新打开引导，重做第 3 步。登录需在弹出的 Edge 窗口中完成，检测到登录会自动保存。

**采集不到故事？**
确认 URL 是作者的「回答列表页」（`zhihu.com/people/xxx/answers` 而非主页）；确认已登录知乎；作者回答很少或隐私受限时可能采集不到。

**生成的故事没有发布到知乎？**
完整链路与批量运行都会写入草稿；环节测试中的「生成」只存盘。草稿可在知乎 App/网页的「草稿箱」找到，确认后手动发布。

**Web 网页版通道需要登录吗？**
需要。首次使用某个网页版大模型时会在 Edge 中打开其网站要求登录一次，登录态随浏览器配置持久保存。

**升级安装会丢数据吗？**
不会。数据位于 `%APPDATA%\AutoQuill\`，与程序目录分离。

**如何查看运行日志？**
控制台日志框实时显示；完整日志在 `%APPDATA%\AutoQuill\logs\`。

**应用内更新失败怎么办？**
安装包会保留，可在 `%APPDATA%\AutoQuill\data\update\` 找到并手动安装；
换装过程日志写入同目录的 `apply.log`。

## 卸载

「设置」→「应用」→ 找到 AutoQuill → 卸载；或使用安装目录下的 `unins000.exe`。

卸载不会删除 `%APPDATA%\AutoQuill\` 中的数据。如需彻底清理，手动删除该目录。
